This web application provides users with the capability to filter and analyze the annual income statement data for Apple Inc. (AAPL), obtained from the [Financial Modeling Prep API](https://financialmodelingprep.com). Users can effortlessly filter key financial metrics, sort data, and view the results in an interactive table.

Features

- Fetch and Display Financial Data: The application retrieves annual income statements for AAPL and showcases essential financial metrics, including revenue, net income, gross profit, earnings per share (EPS), and operating income.
- Filter Data: Users can refine their searches by date range, revenue, and net income.
- Sort Data: The app offers the ability to sort information by date, revenue, and net income.
- Responsive Design: The application's fully responsive design ensures an optimal viewing experience on both desktop and mobile devices.
